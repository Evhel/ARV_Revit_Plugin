# ARV_Revit_Plugin — Revit 2022

Версия 1.2.0. Windows x64, .NET Framework 4.8. Вкладка ARV: 11 кнопок в пяти панелях.

## Установка

Скачайте [готовый ZIP](dist/ARV_Revit_Plugin_Revit2022_v1.2.0.zip) и следуйте [инструкции](INSTALL_RU.md).

При закрытом Revit скопируйте папку `ARV` и `ARV_Ribbon.addin` из архива в:

```text
C:\ProgramData\Autodesk\Revit\Addins\2022\
```

Готовые DLL также доступны отдельно в [dist/Revit2022/ARV](dist/Revit2022/ARV). Библиотеки Autodesk в комплект не входят.

## Ручное редактирование

Откройте **[ARV_Revit_Plugin.sln](ARV_Revit_Plugin.sln)** в Visual Studio 2022. Все 12 проектов содержат C#, XAML и `.csproj`; общий исходный код `src/Common` подключён к проектам через Compile/Link и виден в Solution Explorer.

Нужны .NET Desktop Development, .NET Framework 4.8 Developer Pack и установленный Revit 2022. Выберите Release / Any CPU: каждый проект настроен на x64. Основная команда панели — `src/ARV_Ribbon/Class1.cs`.

Сборка и обновление DLL/ZIP:

```powershell
.\build.ps1
# Другая папка установки Revit:
.\build.ps1 -RevitApiPath 'D:\Autodesk\Revit 2022'
```

Скрипт собирает решение, проверяет отсутствие предупреждений и формирует `dist/Revit2022`, ZIP и SHA-256. Ничего не устанавливает в Revit. Прямая сборка через Visual Studio создаёт DLL в `src/<проект>/bin/Release`; ZIP обновляет именно `build.ps1`.

## Агент-разработчик

[Правила разработчика](docs/agents/REVIT_DEVELOPER_RU.md) закрепляют совместимость с Revit 2022, сохранение исходников Visual Studio, транзакции, интеграцию кнопок, общий UI и сборку комплекта. [Проектный профиль revit_developer](.codex/agents/revit_developer.toml) подготовлен для работы из корня этого проекта; глобальные настройки Codex не меняются. Агент проверяет код, сборку и файлы без запуска Revit; команды в Revit пользователь проверяет вручную по короткому списку сценариев.

## Исправление 1.1.1

Убрана проверка динамического `Document.IsReadOnly` из callback доступности кнопок. Она могла выключать все десять команд при открытом проекте. Проверка возможности редактирования выполняется непосредственно при запуске команды. Формулы и поведение остальных команд не менялись. После замены DLL нужен перезапуск Revit.

## Остальные исправления

- «Виды на лист»: алфавитная сортировка по «Имени вида», слева направо и сверху вниз; проверка размещения, поддержка спецификаций и отдельный отчёт о пропусках.
- Исправлены копирование видов, конфликты нумерации, повторный запуск видов по рабочим наборам, обрезка и работа с загруженными штампами.
- Скрытие категорий выполняется в контексте команды без снятия шаблонов с видов.
- Расчёты черновой отделки используют ID типов и проверяют параметры. У чистовой исправлено чтение строковых параметров и обработка ошибок; **формулы и группировка сохранены по указанию владельца**, включая повторное увеличение длины плинтуса.
- Удалены проекты создания потолков, контейнера семейств и ExportNavis.

Подробности по каждой кнопке: [аудит и изменения](docs/AUDIT_RU.md).
