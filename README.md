# ARV_Revit_Plugin

Исходники инструментов ARV для Autodesk Revit 2022 (.NET Framework 4.8, Windows x64).

Снимок существующих проектов и аудит от 15.10.2026. Алгоритмы команд и состав панели сохранены. Наличие исходников и успешная сборка не означают, что все команды проверены в Revit.

## Состав

- `src/ARV_Ribbon` — вкладка ARV, 5 панелей, 11 кнопок.
- Остальные проекты в `src/` — команды, вызываемые панелью.
- `src/CreateCeil` и `src/FamilyContainerModel` — дополнительные проекты без кнопок; исключены из обычной сборки.
- `archive/ExportNavis` — незавершённый проект для Navisworks, сохранён для справки и исключён из сборки Revit.
- [Аудит](docs/AUDIT_RU.md) — найденные проблемы, пропущенные инструменты и границы проверки.

## Сборка

Нужны установленный Revit 2022, Visual Studio 2022 с инструментами разработки .NET Desktop и .NET Framework 4.8 Developer Pack.

В PowerShell из корня репозитория:

```powershell
.\build.ps1
# Если Revit установлен в другом месте:
.\build.ps1 -RevitApiPath 'D:\Autodesk\Revit 2022'
```

Обычная сборка проверена: 12 проектов, ошибок и предупреждений нет. Результат подготовки пакета — `artifacts/package/`, журналы — `artifacts/`.

`-IncludeExperimental` включает оба дополнительных проекта. Сейчас такая сборка ожидаемо завершается ошибкой в `CreateCeil` (см. аудит).

## Установка

Скрипт только собирает пакет и ничего не устанавливает. После исправления замечаний и проверки на тестовой модели, при закрытом Revit можно разместить содержимое `artifacts/package/` в `C:\ProgramData\Autodesk\Revit\Addins\2022\` с сохранением структуры: манифест рядом с папкой `ARV`, DLL и PNG внутри `ARV`.

Исходная панель использует именно этот фиксированный путь для DLL. Иконки в пакете копируются из `src/ARV_Ribbon/Images`; логотип ARV берётся из `assets/installed-icons/ARV.png`, поскольку установленный логотип отличается от исходного. Обе версии сохранены. Autodesk DLL в репозитории и пакете отсутствуют; используются библиотеки установленного Revit.

В репозитории нет пользовательских моделей, кэшей Visual Studio, `bin/obj`, токенов GitHub и старых копий сторонних библиотек. Ссылка кнопки ARV сохранена из исходников; её доступность не проверялась.
