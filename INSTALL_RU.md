# Установка ARV для Revit 2022 — версия 1.4.3

1. Закройте все окна Revit 2022.
2. Сохраните резервную копию прежней папки ARV и ARV_Ribbon.addin вне папок Addins, например в Документы\ARV_backup.
3. Распакуйте архив. Скопируйте из него **папку ARV** и **файл ARV_Ribbon.addin** в:

   C:\ProgramData\Autodesk\Revit\Addins\2022\

   Для записи в ProgramData Windows может запросить права администратора.
4. Замените старые DLL и PNG. Проверьте структуру:

   C:\ProgramData\Autodesk\Revit\Addins\2022\ARV_Ribbon.addin
   C:\ProgramData\Autodesk\Revit\Addins\2022\ARV\ARV_Ribbon.dll
   C:\ProgramData\Autodesk\Revit\Addins\2022\ARV\PlaceViewsOnSheet.dll
   ... остальные DLL и PNG находятся в той же папке ARV.

5. Должен остаться один манифест панели ARV: ARV_Ribbon.addin непосредственно в папке 2022. Если старый ARV_Ribbon.addin лежит ещё и внутри ARV или в %APPDATA%\Autodesk\Revit\Addins\2022, перенесите лишнюю копию в резервную папку вне Addins. Другие плагины не трогайте.
6. Запустите Revit 2022. На вкладке ARV должно быть 14 кнопок в семи панелях.

Не копируйте в Addins исходники, bin/obj, файлы тестов и библиотеки RevitAPI.dll/RevitAPIUI.dll. Они не нужны для установки. INSTALL_RU.md и SHA256SUMS.txt можно оставить рядом с архивом.

## Виды на лист

Выберите виды в диспетчере проекта → «Виды на лист» → лист, шаг и число видов в ряду.
Порядок — алфавитный по параметру «Имя вида», русская сортировка без учёта регистра. Размещение идёт слева направо и сверху вниз. Уже размещённые и неподходящие виды пропускаются с объяснением; поддерживаются также размещаемые спецификации. Шаг задаётся между точками размещения; размер видов и свободное место на листе автоматически не подбираются.

## Отделка

Для расчётов нужны проектные параметры ВО_* и ADSK_Группирование. При отсутствии нужного параметра или невозможности записи операция прекращается с сообщением, изменения откатываются.
По указанию владельца логика «Чистовой отделки» сохранена, включая повторное увеличение ADSK_Длина плинтуса на коэффициент запаса при каждом запуске. Этот расчёт пока не изменён.

## Выпуск 1.4.3 — основы армирования

В панели «Армирование» две новые кнопки:

- «Сменить основу АП»: нажать → выбрать армирование по площади → выбрать новую основу.
- «Основы АП на этаже»: выделить зоны → нажать → выбрать стену нужного этажа. Её базовый уровень задаёт этаж поиска, а соответствующие стены определяются по нижней границе каждого контура.

Верх контура может быть выше стены; контур не обрезается и не перемещается. При нескольких совпадениях или ошибке исходная зона сохраняется. При успешной замене меняется ID; старые марки/размеры могут потеряться. После обработки появляется отчёт.

Копируйте комплект целиком, включая AreaReinforcementHosts.dll и две новые PNG, при закрытом Revit. Отдельный манифест для новых кнопок не нужен. Полная инструкция и ограничения — docs/AREA_REINFORCEMENT_HOSTS_RU.md в репозитории.

Перенос проекта в 0,0 остаётся в панели «Модель». Все окна используют центрирование на мониторе текущего сеанса Revit.

## Что проверено

Сборка 14 проектов без предупреждений, алгоритмы, расчёт центра окна, одиннадцать компоновок, рендеры 100/125/150/200%, метаданные DLL и состав/хеши ZIP. Команды и фактическую смену основ в Revit пользователь проверяет вручную, начиная с копии модели.
