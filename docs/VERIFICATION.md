## Что не проверено

Обнаружен существующий Revit 2022.1 с открытым «Проект1». Попытка захвата окна вернула `FrameArrived timed out: timed out waiting on channel`; повторная после обновления окна и активации — `window capture timed out: timed out waiting on channel`. Команды в модели не запускались, тестовые элементы не создавались, установленный комплект не заменялся.

Таким образом, проверки сборки, WPF и упаковки выполнены, полная проверка команд внутри Revit — нет. Это ограничение не скрыто за успешным результатом MSBuild.

## Повторная проверка

Сначала из корня репозитория выполните `build.ps1`. Тесты можно собрать MSBuild из Visual Studio Developer PowerShell:

```powershell
msbuild .\tests\AlgorithmTests.csproj /t:Rebuild
.\artifacts\algorithm-tests\ARV.AlgorithmTests.exe
powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\check-wpf.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\verify-package.ps1
```

`tests/NativeChecks.csproj` — дополнительный исходный код проверки в Revit через Add-In Manager (Manual Mode); DLL не входит в поставку. Он компилируется, но **не запускался** в этой сессии. Использовать только на тестовой копии модели. Тест формирует временные элементы и параметры, вызывает реальные команды/методы, а затем откатывает TransactionGroup и восстанавливает исходное выделение. Во время теста нужно подтвердить окна копирования, размещения и нумерации. Для размещения выбрать созданный тестовый лист; для нумерации оставить старт 1. Скрипт использует папку репозитория относительно своей DLL в artifacts/native-checks; отчёт пишет в artifacts/native-checks-report.txt.

Наличие исходника NativeChecks не является доказательством прохождения проверки в Revit.
