# Проверка выпуска 1.3.0

- 13 проектов собраны через build.ps1 без ошибок и предупреждений.
- 20 проверок общих алгоритмов, 39 проверок вспомогательной логики переноса (9 порядка видов, 15 сохранения оформления, 15 горизонтальных/внутривидовых смещений) пройдены без запуска Revit.
- Четыре файла ядра переноса совпадают побайтно с отдельным проектом 1.0.20: [происхождение и SHA-256](origin-source-provenance.json).
- 8 сценариев расчёта центра рабочей области: смещённые и отрицательные координаты мониторов, разные размеры в экранных координатах, слишком большое окно. Для десяти окон проверено отсутствие конфликтующего CenterOwner/CenterScreen. Дополнительно проверен реальный Win32-перенос скрытого тестового окна в центр монитора при сдвинутом вниз скрытом владельце. Тест не использует окно Revit; его фактическое положение пользователь проверяет вручную.
- Загружены десять рабочих компоновок WPF; обработчики сверены с собранными классами. 40 рендеров при 100/125/150/200%, десять маленьких окон с ошибкой; нижние кнопки доступны. Для переноса подтверждено сохранение безопасного действия по умолчанию «Отмена».
- Проверены реальные конструкторы окон нумерации, копирования, размещения и переноса без доступа к документу. Проверены ошибки ввода, переключение замены текста и значения сводки переноса.
- SVG и PNG новой иконки сохранены, PNG: 32×32 RGBA, прозрачный внешний фон, около 96 DPI; проверены поля и вид на трёх фонах.
- Все 13 DLL: версия 1.3.0.0, x64, Revit API 22. Проверены 12 привязок кнопка → DLL → класс → availability → PNG и манифест.
- Все 28 файлов ZIP сопоставлены с пакетом по SHA-256; проверена контрольная сумма самого ZIP. Исключённые команды, SelfTest и диагностические типы не входят в производственную сборку переноса; библиотеки Autodesk и тестовые DLL отсутствуют в поставке.

[Метаданные](release-verification.json), [контрольные суммы](../dist/Revit2022/SHA256SUMS.txt), [перенос и ручная проверка](ORIGIN_RELOCATOR_RU.md), [правила центрирования](design/UI_STYLE_RU.md).

Команды, фактическое центрирование и переключение DPI в Revit пользователь проверяет вручную. Revit не запускался, управление им не использовалось, установка и модель не менялись. Рендеры используют демонстрационные данные и не проверяют изменение модели. Полный перенос проекта в составе панели ещё требует ручной проверки.
