# Проверка выпуска 1.2.0

- Решение из 12 проектов собрано через build.ps1 без ошибок и предупреждений.
- 20 регрессионных проверок общих алгоритмов пройдены.
- Девять рабочих компоновок WPF загружены без запуска Revit; обработчики сверены с собранными классами. Проверены основная кнопка и Enter/Esc.
- Отрисовано 36 вариантов при 100/125/150/200% и девять маленьких окон с ошибкой ввода; нижние кнопки доступны. Визуально просмотрены общие галереи и окно размещения при 200%.
- Проверены реальный конструктор окна нумерации, переключение типа, допустимые значения и ошибка внутри формы. Буквенная последовательность продолжается после Я. Реальные конструкторы копирования и размещения проверены с пустыми списками; проверены переключатель замены текста и ошибки ввода без доступа к модели.
- Все 12 DLL имеют версию 1.2.0.0, архитектуру x64 и ссылки на Revit API 22. Проверены 11 привязок кнопка → DLL → класс → availability → PNG и манифест.
- Все 26 файлов ZIP сопоставлены с папкой пакета по SHA-256. Исключённые команды, тестовые DLL и библиотеки Autodesk отсутствуют.

[Метаданные выпуска](release-verification.json), [контрольные суммы](../dist/Revit2022/SHA256SUMS.txt), [изменения UI и ручная проверка](UI_RELEASE_1_2_0_RU.md).

Проверку команд в Revit пользователь выполняет вручную. Revit не запускался и управление им не использовалось. Установка и модель не изменялись. Загрузка макетов выполняется с демонстрационными данными и без модельных конструкторов; реальная работа команд, окна владельца и смена монитора остаются для ручной проверки.

## Повторение проверок без Revit

Из корня проекта:

```powershell
.\build.ps1
msbuild .\tests\AlgorithmTests.csproj /t:Rebuild
.\artifacts\algorithm-tests\ARV.AlgorithmTests.exe
powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\check-wpf.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\verify-package.ps1
```

Рендеры сохраняются в artifacts/ui-review. Для проверки метаданных и загрузки зависимостей нужны DLL API установленного Revit 2022; само приложение не запускается. Старые исходники NativeChecks оставлены как исторические вспомогательные материалы, в проверки этого выпуска и поставку они не входят.
