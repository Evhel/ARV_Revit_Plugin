# UI ARV — выпуск 1.2.0

Девять окон настройки получили светлую тему ARV, фиолетовую основную кнопку, поля от 32 DIP, подписи над полями, общий заголовок с иконкой и закреплённую нижнюю панель. Центральная часть прокручивается; окно можно расширить. Высота и ширина ограничиваются рабочей областью монитора владельца при открытии. Ошибки ввода показываются внутри формы, переводят фокус к полю и сохраняют введённый текст.

[Галерея](design/UI_GALLERY.png) — отрисовки рабочих XAML с демонстрационными данными. Это не снимки установленного плагина. Обычная системная рамка Windows за пределами изображений.

## Редактируемые исходники

- [ArvTheme.xaml](../src/Common/ArvTheme.xaml) — общий словарь цветов и стилей, подключённый в каждый проект окна через Page/Link.
- [UiSupport.cs](../src/Common/UiSupport.cs) — оформление ошибки и ограничение размеров окна, без работы с документом Revit.
- XAML и существующие обработчики находятся в папке каждой команды. [NumberingDialog.xaml](../src/ViewNumberingPlugin/NumberingDialog.xaml) заменяет прежнюю программную компоновку нумерации.
- Иконки встроены в DLL соответствующих команд. В установке по-прежнему 12 DLL, 11 PNG и один .addin; дополнительная DLL темы не нужна.

Формулы отделки, порядок транзакций и область обработки сохранены. «Виды на лист» сохраняет сортировку по параметру «Имя вида». Списки показывают исходный выбор целиком; выделение строки не исключает её из обработки. Команда сайта и создание 3D-видов по рабочим наборам не имели окон настройки: новые окна для них не добавлялись, системные сообщения сохранены.

## Ручная проверка пользователем

После установки при закрытом Revit откройте проект и проверьте окна. Для расчётных команд используйте копию модели с нужными параметрами.

| Команда | Что проверить |
|---|---|
| Черновая отделка | Фильтр группы, пять столбцов типов, коэффициент; ошибка при отсутствии типа или повторении типа в столбцах; расчёт по прежним правилам |
| Чистовая отделка | Выбор групп стен/потолков, коэффициент, запуск и отмена; существующая логика повторного увеличения длины плинтуса сохранена |
| Скрыть категорию | Выбор категории, подтверждение области действия, отмена без изменений |
| Скрыть подкатегорию | Обновление списка при смене категории, выбор подкатегории, подтверждение и отмена |
| Создать чистые листы | Тип основной надписи, количество, ошибка для нуля, создание и отмена |
| Копировать виды | Число и тип копий, включение замены текста, предпросмотр, прокрутка до всех полей |
| Виды на лист | Выбор листа, шаг с точкой/запятой, количество в ряду; размещение по имени вида слева направо и сверху вниз |
| Обрезать виды | Отступ, включая отрицательный; переключатели источников; ошибка при отключении обоих |
| Нумерация видов | Цифры/заглавные/строчные, начальное значение, ошибка ввода и применение к выбранным экранам |

Для каждого окна: Tab, Enter, Esc и закрытие крестиком; изменение размеров и прокрутка; длинные имена. При используемом масштабе Windows убедитесь, что кнопки доступны. Владельца окна, реальную работу на мониторах с разным DPI и действия с моделью проверяет пользователь.

## Проверки без Revit

Проверены сборка решения, алгоритмы и пакет. Все девять рабочих XAML загружены отдельно, их обработчики сверены с методами собранных классов. Сохранены ранее именованные контролы; из обрезки удалено только дублирование клавиш Enter/Esc, обслуживаемых IsDefault/IsCancel.

Сделаны 36 рендеров содержимого окон при 96/120/144/192 DPI и девять рендеров маленьких окон 440×360 DIP с многострочной ошибкой. Проверены цвет основного действия и границы нижних кнопок. Визуально просмотрены галереи обычных и маленьких окон, а также «Виды на лист» при 200%. Для нумерации дополнительно проверены реальный конструктор собранного окна и обработка корректного/ошибочного ввода. Для копирования и размещения проверены реальные конструкторы с пустыми списками, переключение замены текста и ошибки ввода без доступа к модели.

Рендеры используют демонстрационные данные и не вызывают конструкторы, которым нужен документ Revit. Они не доказывают работу команды или переключение DPI в самом Revit. Команды в Revit не запускались по договорённости с пользователем.
