# Создать виды элемента

- Направления по локальным осям элемента в плане. Для семейства — GetTransform; для линейного элемента — направление его линии; при отсутствии осей явно сообщай о применении осей проекта. Вертикаль боковых видов — Z проекта.
- Все виды создаются ViewSection.CreateSection, включая три горизонтальных разреза на отметках от минимальной Z габаритов. Не заменяй их ViewPlan или Detail без нового запроса.
- Отбор одного экземпляра: минимальная Z габаритов, затем минимальный X, затем максимальный Y, затем ID. При включённом отборе пустые/отсутствующие значения исключай; без отбора сохраняй все элементы. Параметр можно использовать для названий без включения отбора.
- Соседние элементы остаются видимыми. Исходные элементы не скрывай, не перемещай и не включай в сборку.
- Шаблон каждого включённого вида обязателен. Передавай выбор по ID, проверяй ViewTemplateId после назначения/регенерации и перед Commit. Масштаб бери только из шаблона, ручного масштаба нет. Названия включают выбранное значение либо порядковый номер; занятые имена не переименовывай.
- Ошибка создания/шаблона откатывает новые виды элемента. Ошибка создания листа или размещения не откатывает уже созданные виды. Не поместившиеся экраны сохраняй за правой границей листа, сообщай об этом. Тип экрана выбирается для каждого вида. Не меняй масштаб ради размещения.
- Название над видом — отдельный TextNote на листе, по центру над рамкой. Сохраняй это отличие от штатного заголовка типа экрана и пояснение о ручном переносе/переименовании.
- Настройки сохраняются/загружаются в JSON; ссылки проверяй по именам перед принятием ID, чужие ID из другого проекта не назначай молча. При неразрешённом выборе не меняй текущую форму.
- Не запускай Revit и не подключайся к нему. Проверку в модели выполняет пользователь. Исходники, solution, DLL, инструкция и ZIP сохраняются в репозитории.
