# Смена основ армирования по площади

- Массовая команда определяет этаж по базовому уровню выбранной стены, а соответствующие стены — по нижней границе фактического контура зоны.
- Не проверяй полное вписывание контура в стену: по прямому указанию владельца его верх обычно выше стены. Не обрезай и не перемещай исходный контур.
- Одиночная команда использует явно указанную основу; массовая не выбирает первую стену при неоднозначности.
- Владелец разрешила пересоздание со сменой ID и потерей связанных старых марок/размеров. Новую зону всё равно создавай и проверяй до удаления старой; ошибка отдельной зоны должна откатывать её замену.
- Настройки, ручные правки и ограничения переноса описаны в ../../docs/AREA_REINFORCEMENT_HOSTS_RU.md. Проверку в Revit выполняет пользователь вручную.

- Не включай четыре REBAR_SYSTEM_*_MATCHES_* в снимок переносимых параметров: это служебные признаки сравнения слоёв. Отказ их Set при IsReadOnly=false ранее давал 134 ложных пропуска. Проверяй реальные настройки слоёв; не ослабляй проверку всех параметров ради обхода ошибки.
